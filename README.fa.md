# راست‌چین فارسی برای اوپن‌کد

یک پچ کوچک برای خواناتر شدن متن‌های فارسی و ترکیبی در نسخهٔ رومیزی اوپن‌کد روی ویندوز.

**[English README](README.md)**

> [!WARNING]
> این پروژه رسمی نیست و بستهٔ داخلی رابط اوپن‌کد را تغییر می‌دهد. نصب‌کننده قبل از هر تغییری از فایل اصلی نسخهٔ پشتیبان می‌گیرد، با این حال باید پیش از نصب، اوپن‌کد را کامل ببندید.

## مشکل چیست؟

رابط اوپن‌کد جهت ثابتی برای متن گفتگو دارد. به همین دلیل پیام‌هایی که فارسی و انگلیسی را کنار هم دارند، معمولاً بهم‌ریخته و سخت‌خوان نمایش داده می‌شوند.

این پچ جهت هر بخش از پیام را جداگانه تشخیص می‌دهد:

| نوع متن | نحوهٔ نمایش |
| ---: | ---: |
| متن دارای حروف فارسی یا عربی | راست‌چین و راست‌به‌چپ |
| متن کاملاً انگلیسی | چپ‌چین و چپ‌به‌راست |
| کد و دستورها | همیشه چپ‌به‌راست |

فونت وزیرمتن هم برای کاربر فعلی ویندوز نصب می‌شود تا نوشته‌های فارسی خواناتر نمایش داده شوند.

## نصب سریع

ابتدا اوپن‌کد را کامل ببندید. فایل فشردهٔ آخرین انتشار را دانلود و از حالت فشرده خارج کنید. سپس پاورشل را در همان پوشه باز کنید و دستور زیر را اجرا کنید:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-OpenCodePersianRTL.ps1
```

پس از پایان نصب، اوپن‌کد را دوباره باز کنید.

## پیش‌نیازها

- ویندوز ده یا یازده
- نسخهٔ رومیزی اوپن‌کد
- اینترنت برای دریافت وابستگی‌ها و فونت در اولین اجرا

این نسخه‌ها یا نسخه‌های جدیدتر نیز لازم‌اند:

```text
PowerShell 5.1
Node.js 22.12
```

## گزینه‌های نصب

اگر اوپن‌کد در مسیر دیگری نصب شده، مسیر فایل داخلی برنامه را دستی وارد کنید:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-OpenCodePersianRTL.ps1 -AppAsar "C:\path\to\resources\app.asar"
```

اگر فقط راست‌چین را می‌خواهید و نیازی به وزیرمتن ندارید:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-OpenCodePersianRTL.ps1 -SkipFontInstall
```

## برگرداندن تغییرات

اوپن‌کد را ببندید و این دستور را اجرا کنید:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-OpenCodePersianRTL.ps1 -Action Restore
```

نصب‌کننده هش فایل فعلی و نسخهٔ پشتیبان را با مقادیر ثبت‌شده هنگام نصب مقایسه می‌کند و در صورت مغایرت، بازیابی را متوقف می‌کند. نگه‌دارندهٔ خودکار هم غیرفعال می‌شود تا پچ دوباره برنگردد. وزیرمتن حذف نمی‌شود، چون ممکن است برنامه‌های دیگر هم از آن استفاده کنند.

## نصب خودکار بعد از به‌روزرسانی

برای اینکه پچ بعد از هر به‌روزرسانی خودکار برگردد، این قابلیت را یک‌بار فعال کنید:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-OpenCodePersianRTL.ps1 -Action EnableAutoMaintenance
```

از این به بعد اگر به‌روزرسانی فایل رابط را عوض کند، نگه‌دارنده صبر می‌کند تا تغییر فایل متوقف شود و سازگاری آن را بررسی می‌کند. سپس اوپن‌کد را به‌شکل عادی می‌بندد، پچ را نصب می‌کند و برنامه را دوباره باز می‌کند. اگر برنامه عادی بسته نشود، هیچ فرایندی به‌زور متوقف نمی‌شود و نگه‌دارنده بعداً دوباره تلاش می‌کند.

برای خاموش‌کردن این قابلیت بدون حذف پچ فعلی:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-OpenCodePersianRTL.ps1 -Action DisableAutoMaintenance
```

## بعد از به‌روزرسانی اوپن‌کد

به‌روزرسانی برنامه معمولاً فایل پچ‌شده را با نسخهٔ تازه جایگزین می‌کند. اگر نگه‌دارنده را فعال کرده باشید، پچ و راه‌اندازی دوبارهٔ برنامه خودکار انجام می‌شوند. در غیر این صورت باید نصب‌کننده را دوباره اجرا کنید.

نسخهٔ فعلی با این نسخه از اوپن‌کد آزمایش شده است:

```text
OpenCode Desktop 1.18.10
```

اگر ساختار رابط در نسخه‌های بعدی تغییر کند، نصب‌کننده بدون دست زدن به برنامه متوقف می‌شود.

## پشت صحنه

نصب‌کننده بستهٔ رابط را استخراج می‌کند، کد تشخیص جهت و فونت را به آن اضافه می‌کند و بسته را دوباره می‌سازد. قبل از جایگزینی، خروجی و نسخهٔ پشتیبان با هش بررسی می‌شوند. ماژول‌های باینری برنامه هم بدون تغییر باقی می‌مانند.

نسخهٔ وابستگی‌ها در فایل قفل ثبت شده است. هنگام دریافت آن‌ها نیز هیچ اسکریپت جانبی اجرا نمی‌شود. آزمون نصب و بازیابی با هر تغییر مخزن روی ویندوز اجرا می‌شود.

گزارش کار نگه‌دارنده در مسیر زیر نوشته می‌شود:

```text
%LOCALAPPDATA%\OpenCodePersianRTL\maintenance.log
```

## مشارکت

اگر پچ روی نسخه‌ای از اوپن‌کد کار نکرد یا بخشی از متن هنوز بهم‌ریخته بود، یک ایشو باز کنید. برای مشارکت در کد هم می‌توانید پول ریکوئست بفرستید.

پیش از ارسال تغییرات، آزمون‌ها را اجرا کنید:

```powershell
npm ci --ignore-scripts --no-audit --no-fund
npm test
```
